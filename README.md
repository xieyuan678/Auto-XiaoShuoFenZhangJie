# 小说TXT文件分割工具

一款用于将小说TXT文件自动分割成多个章节的工具。

## 功能特点

- **智能分章**：按设定的最小字数自动分割章节（取到句号为止）
- **灵活设置**：支持1200字、2400字或自定义字数
- **自动命名**：智能提取章节标题，格式为"第X章 标题"
- **编码兼容**：支持UTF-8、GBK、GB2312、GB18030编码
- **自动合并**：最后一章字数不足时自动合并到上一章
- **空行清理**：自动清理文本中的空行
- **起始章节**：支持自定义起始章节编号

## 使用方法

1. 将 `小说自动分割工具.exe` 复制到包含小说TXT文件的文件夹
2. 双击运行程序
3. 根据提示选择每章节最小字数（A/B/C）
4. 等待处理完成

## 使用提示

- 程序会扫描当前目录下所有 `.txt` 文件
- 已生成的章节文件（第X章开头）会被跳过
- 处理结果会写回原文件
- 支持命令行参数 `--start` 设置起始章节数
